“Please explain the concept of idempotency in infrastructure as code (IaC) and cloud operations. Give a 30-60 second explanation as if you’re introducing the concept to a first-year computer science class.”

Expected Answer Highlights:
	•	Definition: An operation is idempotent if performing it multiple times produces the same result as performing it once.
	•	In Infrastructure as Code: Tools like Terraform or CloudFormation use idempotency to ensure that reapplying code doesn’t change the infrastructure if it’s already in the desired state.
	•	Benefits: It ensures consistency, prevents accidental changes, and makes infrastructure management predictable and safe.

Follow-up: "Please explain how IaC tools like Terraform ensure idempotency in practice."

Expected Answer Highlights:
    •	Terraform State: Terraform uses a state file to track the current state of the infrastructure.
    •	Plan-Apply Workflow: Terraform compares the desired state (defined in code) with the current state (from the state file) to determine what changes are needed.
    •	Execution Plan: Terraform generates an execution plan that shows what will change before applying it.
    •	Apply Step: Terraform applies the changes to the infrastructure to reach the desired state.
    •	Reconciliation: Terraform’s idempotency comes from this workflow, where it reconciles the desired state with the current state to make only the necessary changes.
